Kiểm tra

Cách dùng

  1. Mở file này bằng trình duyệt bất kỳ. Không cần mạng, không cần server.
  2. Chọn số ngày, số lượng → bấm Tạo key.
  3. Bấm vào key để copy, hoặc Copy tất cả / Tải .txt.
  4. Gửi key cho người dùng, họ nhập vào màn đăng nhập của app.

Khóa theo thiết bị

Người dùng lấy android_id bằng một trong các cách sau, gửi cho bạn, bạn dán vào ô HWID rồi tạo key:

  • adb shell settings get secure android_id
  • App Device ID / Device Info trên CH Play → mục Android ID
  • Cài Termux: settings get secure android_id

Mỗi android_id tạo đúng một key. Key đó cài sang máy khác sẽ báo "Key khong dung thiet bi".

Kỹ thuật

  • Key: MVIP + Crockford base32 của 14 byte.
  • 14 byte = 4 byte hạn (ngày từ epoch) + 4 byte tag thiết bị + 2 byte serial + 4 byte chữ ký.
  • Tag thiết bị = 4 byte đầu HMAC-SHA256(secret, "h:" + android_id). Tag 0 = dùng mọi máy.
  • Chữ ký = 4 byte đầu HMAC-SHA256(secret, 10 byte đầu).
  • App kiểm tra hoàn toàn offline — không cần server, không sợ sập host.
